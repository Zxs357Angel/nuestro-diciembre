NUESTRO DICIEMBRE 2026

ARCHIVOS
- index.html: página principal.
- style.css: diseño adaptable a celular.
- script.js: calendario, mensajes y desbloqueo.
- manifest.webmanifest: configuración PWA.
- sw.js: caché básica para uso sin conexión después de la primera carga.
- icons/: iconos PNG de 192 y 512 px, normales y maskable.
- preview.html: vista previa con todas las casillas abiertas.

PUBLICAR EN GITHUB PAGES
1. Extrae este ZIP.
2. Entra al repositorio nuestro-diciembre.
3. Sube TODO el contenido de esta carpeta a la raíz del repositorio (no subas la carpeta contenedora).
4. En GitHub: Settings > Pages.
5. En Build and deployment, elige Deploy from a branch.
6. Selecciona la rama main y la carpeta /(root), guarda.
7. Espera a que GitHub Pages publique el sitio.

VISTA PREVIA
Abre preview.html localmente o, una vez publicado, visita:
https://TU-USUARIO.github.io/nuestro-diciembre/preview.html

HORARIO
El calendario utiliza America/Mexico_City. Cada día se desbloquea a las 08:00 a. m. hora local de Ciudad de México, independientemente del país desde el que se abra.

PWABUILDER
El manifiesto incluye iconos PNG de 192x192 y 512x512 con purpose any, y versiones maskable. La página debe estar publicada mediante HTTPS para analizarla con PWABuilder.

NOTA
La vista previa abre todos los días para probar el contenido. La página principal mantiene el bloqueo por fecha y hora.
